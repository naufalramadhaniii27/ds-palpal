# Q5: character portraits (800 portraits, 200 sheets)

The portrait picker gets many more ready portraits: every species, varied roles, ages, genders and poses, searchable in the app. Draw them in the exact style of the 142 portraits already in the app.

THREE TESTS FOR EVERY PORTRAIT (Claude rejects any portrait that fails one): 1. ART STYLE: matches the style reference exactly. 2. CONTEXT: shows exactly the species, role, framing and pose of its line, the species recognisable at a glance. 3. UNIQUE: no two portraits share the same pose, framing and angle, the set must look varied, never uniform.

## Rules

1. Work only on branch art-tasks. Never touch main.
2. CLAIM, NO LANES. Any number of sessions can run at once. Take the first sheet in the Status table whose status cell is empty: write "claimed by <your session id> <UTC time>" in it, commit, git pull --rebase, push at once. If the push conflicts, pull and take the next empty sheet. Never work on a sheet someone else claimed. A claim older than 3 hours with no pushed image is stale: you may take it over.
3. Each sheet = ONE image: 1024x1536 PNG (portrait orientation), 2x2 layout: cell 1 top-left, 2 top-right, 3 bottom-left, 4 bottom-right, each cell 512x768. Each cell is one full portrait card: the character plus its own brushed colour background filling the whole cell. A thin gap of plain cream (#F4EAD5) between cells. No borders, frames, labels, numbers or text.
4. STYLE LOCK. Attach art-tasks/q5/style-ref-portrait.png (16 approved app portraits) to EVERY generation. Generate each sheet as new members of that exact set: anime-influenced illustration, confident ink line, loose painterly colour with visible brush texture, rough brushed two-colour background with a ragged edge, warm light, expressive faces, worn adventuring gear. Do not change the prompt text except the CELLS lines.
4a. Keep the face and the head fully inside the cell, with room above the head. Faces are clear and readable, eyes visible.
4b. ONE PORTRAIT, ONE POSE. Use the exact pose, angle, framing and expression of the line. Never the stock pose of the old set (hand on the chest, head tilted, looking down). Never an open hand reaching toward the viewer.
4c. CORRECT ANATOMY: head, chest and hips face possible directions, correct number of fingers, arms, horns, ears.
4d. Every person is an adult. Light scrapes and dirt are fine, no blood splatter, no gore, no nudity.
5. NO WAITING. Keep working sheet after sheet. Before each new sheet: git pull --rebase, and first redo every sheet marked "redo" that nobody claimed for redo (write "redo claimed by <id>", push, redraw the whole sheet, push, write "redo done, waiting").
6. Save art-tasks/q5-out/P0NNN.png. Commit "q5: P0NNN" (several per commit is fine), git pull --rebase, push.
7. Claude checks every sheet for the three tests and writes "approved by Claude" or "redo: cells ... (reason)". Do not run checks or scripts on the images. Just generate, save and push.
