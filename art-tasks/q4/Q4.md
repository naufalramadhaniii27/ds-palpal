# Q4: icons for feats, species, backgrounds, class options, bastion rooms and languages (1062 icons, 266 sheets)

These entries show a plain line icon in lists and a blank top in the detail sheet. Draw them in the same quality as the HD sheets H01 to H24 (same method, a wider style reference: art-tasks/q4/style-ref-icons.png). 2014 copies and later stages of the same feat reuse one icon, so they are not in this list.

## Rules

THREE TESTS FOR EVERY ICON (Claude rejects any icon that fails one): 1. ART STYLE: matches the style reference exactly. 2. CONTEXT: shows exactly the subject of its line (DRAW), recognisable at a glance. 3. UNIQUE: it does not repeat the pose, layout or base object of other icons, the set must look varied, never uniform.

1. Work only on branch art-tasks. Never touch main.
2. CLAIM, NO LANES. Any number of sessions can run at once. Take the first sheet in the Status table whose status cell is empty: write "claimed by <your session id> <UTC time>" in it, commit, git pull --rebase, push at once. If the push conflicts, pull and take the next empty sheet. Never work on a sheet someone else claimed. A claim older than 3 hours with no pushed picture is stale: you may take it over (write your own claim over it).
3. Each sheet = ONE image: 1254x1254 PNG, transparent background. 2x2 layout: cell 1 top-left, 2 top-right, 3 bottom-left, 4 bottom-right. Each icon centered in its quarter, about 70% of the quarter, wide empty gap between icons. No grid lines, borders, numbers or labels. A last sheet with fewer cells leaves the rest empty.
4. STYLE LOCK. Attach art-tasks/q4/style-ref-icons.png (16 approved app icons) to EVERY generation, not only the first. Generate each sheet as new members of that exact set, never from memory and never "improved". Hold every point of the Style block in the prompt. Do not change the prompt text except the CELLS lines.
4c. UNIQUE, NOT UNIFORM. No two icons in a sheet, or in the sheets just before it, may share the same base object or layout (no row of books with a clasp, no row of amulets, no row of glowing hands). Vary the object type, the angle (front, three-quarter, top-down, tilted) and the silhouette. When DRAW names a common object, make it distinctive through its shape, material and one memorable detail.
4b. CONTEXT FIRST. Every cell line starts with DRAW: that is the subject, draw exactly that so a player can tell what the entry is at a glance. CONTEXT: is background only, never draw its words or numbers. If DRAW lists choices, pick the clearest ones. Keep one clear focal object, not a busy pile.
4a. NEVER COPY A REFERENCE ICON. The reference shows the technique only. Do not reuse its objects or compositions (the hammer and anvil, the straw target, the cloak on a hanger, the anchor, the bell, the book stack, the quill). Every icon must be a new object chosen from the cell text.
5. NO WAITING. There is no trial gate any more. Keep working sheet after sheet until no empty sheet is left. Before each new sheet: git pull --rebase, and first redo every name marked "redo" in rows you or anyone worked on and nobody has claimed for redo (write "redo claimed by <id>" in that row while you work on it). When the redo is pushed, write "redo done, waiting" in that row.
6. Save art-tasks/q4-out/S0NNN.png. Commit "q4: S0NNN" (several sheets per commit is fine), git pull --rebase, push.
7. Claude checks every pushed sheet for style and for the DRAW subject of every cell, and writes "redo: cells ... (reason)" in the Status row. Approval of the trial is not approval of later sheets. Before each new group, git pull and redo those first.
8. Claude checks, cuts and names every icon. Do not run your own quality checks or scripts on the images. Just generate, save and push.
