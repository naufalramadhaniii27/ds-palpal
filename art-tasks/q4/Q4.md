## Rules

1. Work only on branch art-tasks. Never touch main.
2. Claim your lane in the Status table ("claimed by <session> <time>"), commit, git pull --rebase, push. If the push fails, pull and continue.
3. Each sheet = ONE image: 1254x1254 PNG, transparent background. 2x2 layout: cell 1 top-left, 2 top-right, 3 bottom-left, 4 bottom-right. Each icon centered in its quarter, about 70% of the quarter, wide empty gap between icons. No grid lines, borders, numbers or labels. A last sheet with fewer cells leaves the rest empty.
4. STYLE LOCK. Attach art-tasks/q4/style-ref-icons.png (16 approved app icons) to EVERY generation, not only the first. Generate each sheet as new members of that exact set, never from memory and never "improved". Hold every point of the Style block in the prompt. Do not change the prompt text except the CELLS lines.
4a. NEVER COPY A REFERENCE ICON. The reference shows the technique only. Do not reuse its objects or compositions (the hammer and anvil, the straw target, the cloak on a hanger, the anchor, the bell, the book stack, the quill). Every icon must be a new object chosen from the cell text.
5. TRIAL GATE. Do your first 3 sheets only, push, and STOP. Write "trial done, waiting" in the Status row of your first sheet. Claude compares the trial with the reference and writes "approved by Claude" or "redo: <sheets> (<reason>)" in that row. Continue only after "approved by Claude". Before every new group of sheets, git pull and redo anything marked "redo" first.
6. Save art-tasks/q4-out/S0NNN.png. Commit "q4: S0NNN" (several sheets per commit is fine), git pull --rebase, push.
7. Claude checks, cuts and names every icon. Do not run your own quality checks or scripts on the images. Just generate, save and push.
