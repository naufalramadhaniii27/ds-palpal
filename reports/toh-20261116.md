# Tome of Heroes (2014 rules) import notes (0.0.36)

Source: 5etools homebrew "Kobold Press; Tome of Heroes". Built by tools/tp_build.py (book ttoh, file src/data/tp22-ttoh.js). Test: tests/tp_toh.py (57 checks at 390x844 and 1250x850).

Built
- Subclasses: 81 for all classes, with always-prepared spells, trackers and actions.
- Spells: 140. Items: 50 magic items, 91 gear rows, 35 weapon and armor texts. Cestus +N now adds its bonus to the Unarmed Strike row (name regex in the sheet handler and the item meta).
- Species: 44 (4 plain races, 40 subraces; each subrace is its own species with the parent traits included). The 12 Darakhul heritages are species named "<Race> Heritage". Gearforged chassis are "<Race> Chassis".
- Backgrounds: 19, each with an origin feat and three ability scores like the other 2014 books.
- Feats: 15. Draconic Rune Casting offers a pick of 42 runes. Gunfighting is a fighting style open to every class that has the style pick.
- Options: 19 Eldritch Invocations (with invocation spells), 17 Metamagic options.

Engine changes
- Metamagic and invocations of a book join the 2014 lists (08-logic-2014-rules.js, c14Wl and the metamagic loader) and the 2024 lists (09d wxOpts). OPT rows now accept mm and isp.
- FEATS[n].fsAll opens a fighting style to the 2014 and 2024 style lists (08, 09).
- Test hook __bldData now lists invocations, metamagic and invocation spells, and takes an optional rules edition.
- Four subclasses share a name with another book. They are built as Shadow Domain (ToH), Oath of the Hearth (ToH), Familiar Master (ToH) and Pugilist (ToH), so no tracker of the other book lands on them (invariants found this).

Text only (no counter or picker)
- Rune effects (damage type swaps, DC raises, range and duration changes) are text. Only the pick is tracked.
- Alien Appendage, Tainted Blood and Tenebrous Flesh of the Mutated derro are text inside one trait, not separate options.
- Extinguishing Blast, Lurker in Gloom and Homing Spell: the source text for the light and sight terms is garbled. The rewrite uses bright light, dim light and "cannot see". Check against the book.

Reference only for now (Library phase)
- 17 monsters, 21 variant rules, 11 tables, 15 actions, 5 manors (stronghold options).

Notes
- A full tp_build run rewrites many older tp files because the generator moved ahead of them. Only tp22-ttoh.js was kept from that run.
- mech_scan and solid_data_contract time out or report extra features when another heavy browser test runs at the same time. Run them alone.
